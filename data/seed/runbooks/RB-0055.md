# Mitigating disk pressure on worker nodes on Pricing

## Symptoms

- Disk pressure on worker nodes reported on `svc-pricing`.
- Alert fired from the service SLO burn-rate monitor.
- Customer-facing impact is possible if the condition persists beyond 15 minutes.

## Diagnosis

1. **Check for correlated incidents on dependencies**
   - Command: `atlasctl incidents related svc-pricing`
   - Expected: Open incidents on services this one needs
2. **Confirm the alert is not a monitoring artefact**
   - Command: `atlasctl metrics show svc-pricing --window 15m`
   - Expected: Error rate and p95 both elevated in the same window
3. **Identify the last change to the service**
   - Command: `atlasctl changes list svc-pricing --since 4h`
   - Expected: A change id, or an empty list if none
4. **Check upstream dependency health**
   - Command: `atlasctl deps health svc-pricing`
   - Expected: Each dependency reports healthy or degraded
5. **Inspect the error budget burn rate**
   - Command: `atlasctl slo burn svc-pricing`
   - Expected: Burn rate as a multiple of budget
6. **Review recent log volume for new signatures**
   - Command: `atlasctl logs top-errors svc-pricing --window 30m`
   - Expected: Ranked error signatures with counts

## Mitigation

1. **Fail over to the secondary region**
   - Command: `atlasctl failover svc-pricing --to westeurope`
   - Expected: Traffic served from the secondary region
2. **Scale out the service by one step**
   - Command: `atlasctl scale svc-pricing --replicas +2`
   - Expected: Replica count increases; p95 begins to fall within 3 minutes
3. **Roll back the most recent change**
   - Command: `atlasctl rollback svc-pricing --change CHG-2026-0001`
   - Expected: Previous revision serving traffic
4. **Shed non-critical traffic**
   - Command: `atlasctl traffic shed svc-pricing --class low --percent 25`
   - Expected: Low-priority request volume drops

## Rollback

1. **Revert any scaling change**
   - Command: `atlasctl scale svc-pricing --replicas baseline`
   - Expected: Replica count returns to the baseline
2. **Re-enable any disabled flag once the cause is understood**
   - Command: `atlasctl flags enable pricing-rollout`
   - Expected: Flag reports enabled

## Escalation

- Page `team-commerce` via the primary rotation if not mitigated in 20 minutes.
- Escalate to the incident commander for any Sev1, or if blast radius exceeds 5.
