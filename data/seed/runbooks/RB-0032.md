# Mitigating memory leak in a long-running process on Feature Flags

## Symptoms

- Memory leak in a long-running process reported on `svc-feature-flags`.
- Alert fired from the service SLO burn-rate monitor.
- Customer-facing impact is possible if the condition persists beyond 15 minutes.

## Diagnosis

1. **Review recent log volume for new signatures**
   - Command: `atlasctl logs top-errors svc-feature-flags --window 30m`
   - Expected: Ranked error signatures with counts
2. **Verify connection pool utilisation**
   - Command: `atlasctl pool stats svc-feature-flags`
   - Expected: In-use versus maximum connections
3. **Check for correlated incidents on dependencies**
   - Command: `atlasctl incidents related svc-feature-flags`
   - Expected: Open incidents on services this one needs

## Mitigation

1. **Scale out the service by one step**
   - Command: `atlasctl scale svc-feature-flags --replicas +2`
   - Expected: Replica count increases; p95 begins to fall within 3 minutes
2. **Roll back the most recent change**
   - Command: `atlasctl rollback svc-feature-flags --change CHG-2026-0001`
   - Expected: Previous revision serving traffic
3. **Shed non-critical traffic**
   - Command: `atlasctl traffic shed svc-feature-flags --class low --percent 25`
   - Expected: Low-priority request volume drops
4. **Increase the connection pool ceiling**
   - Command: `atlasctl pool resize svc-feature-flags --max 200`
   - Expected: Pool utilisation falls below 80 percent
5. **Disable the offending feature flag**
   - Command: `atlasctl flags disable feature-flags-rollout`
   - Expected: Flag reports disabled for all cohorts
6. **Purge the affected cache namespace**
   - Command: `atlasctl cache purge svc-feature-flags --namespace hot`
   - Expected: Cache hit ratio recovers over 5 minutes

## Rollback

1. **Revert any scaling change**
   - Command: `atlasctl scale svc-feature-flags --replicas baseline`
   - Expected: Replica count returns to the baseline
2. **Re-enable any disabled flag once the cause is understood**
   - Command: `atlasctl flags enable feature-flags-rollout`
   - Expected: Flag reports enabled

## Escalation

- Page `team-platform` via the primary rotation if not mitigated in 20 minutes.
- Escalate to the incident commander for any Sev1, or if blast radius exceeds 5.
