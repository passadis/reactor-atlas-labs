# Mitigating elevated 5xx error rate on Checkout Api

## Symptoms

- Elevated elevated 5xx error rate reported on `svc-checkout-api`.
- Alert fired from the service SLO burn-rate monitor.
- Customer-facing impact is possible if the condition persists beyond 15 minutes.

## Diagnosis

1. **Confirm the alert is not a monitoring artefact**
   - Command: `atlasctl metrics show svc-checkout-api --window 15m`
   - Expected: Error rate and p95 both elevated in the same window
2. **Identify the last change to the service**
   - Command: `atlasctl changes list svc-checkout-api --since 4h`
   - Expected: A change id, or an empty list if none
3. **Check upstream dependency health**
   - Command: `atlasctl deps health svc-checkout-api`
   - Expected: Each dependency reports healthy or degraded

## Mitigation

1. **Scale out the service by one step**
   - Command: `atlasctl scale svc-checkout-api --replicas +2`
   - Expected: Replica count increases; p95 begins to fall within 3 minutes
2. **Roll back the most recent change**
   - Command: `atlasctl rollback svc-checkout-api --change CHG-2026-0001`
   - Expected: Previous revision serving traffic
3. **Shed non-critical traffic**
   - Command: `atlasctl traffic shed svc-checkout-api --class low --percent 25`
   - Expected: Low-priority request volume drops
4. **Increase the connection pool ceiling**
   - Command: `atlasctl pool resize svc-checkout-api --max 200`
   - Expected: Pool utilisation falls below 80 percent
5. **Disable the offending feature flag**
   - Command: `atlasctl flags disable checkout-api-rollout`
   - Expected: Flag reports disabled for all cohorts

## Rollback

1. **Revert any scaling change**
   - Command: `atlasctl scale svc-checkout-api --replicas baseline`
   - Expected: Replica count returns to the baseline
2. **Re-enable any disabled flag once the cause is understood**
   - Command: `atlasctl flags enable checkout-api-rollout`
   - Expected: Flag reports enabled

## Escalation

- Page `team-commerce` via the primary rotation if not mitigated in 20 minutes.
- Escalate to the incident commander for any Sev1, or if blast radius exceeds 5.
