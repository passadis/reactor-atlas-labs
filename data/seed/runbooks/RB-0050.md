# Mitigating queue backlog growth on Identity

## Symptoms

- Queue backlog growth reported on `svc-identity`.
- Alert fired from the service SLO burn-rate monitor.
- Customer-facing impact is possible if the condition persists beyond 15 minutes.

## Diagnosis

1. **Identify the last change to the service**
   - Command: `atlasctl changes list svc-identity --since 4h`
   - Expected: A change id, or an empty list if none
2. **Check upstream dependency health**
   - Command: `atlasctl deps health svc-identity`
   - Expected: Each dependency reports healthy or degraded
3. **Inspect the error budget burn rate**
   - Command: `atlasctl slo burn svc-identity`
   - Expected: Burn rate as a multiple of budget
4. **Review recent log volume for new signatures**
   - Command: `atlasctl logs top-errors svc-identity --window 30m`
   - Expected: Ranked error signatures with counts
5. **Verify connection pool utilisation**
   - Command: `atlasctl pool stats svc-identity`
   - Expected: In-use versus maximum connections

## Mitigation

1. **Shed non-critical traffic**
   - Command: `atlasctl traffic shed svc-identity --class low --percent 25`
   - Expected: Low-priority request volume drops
2. **Increase the connection pool ceiling**
   - Command: `atlasctl pool resize svc-identity --max 200`
   - Expected: Pool utilisation falls below 80 percent
3. **Disable the offending feature flag**
   - Command: `atlasctl flags disable identity-rollout`
   - Expected: Flag reports disabled for all cohorts
4. **Purge the affected cache namespace**
   - Command: `atlasctl cache purge svc-identity --namespace hot`
   - Expected: Cache hit ratio recovers over 5 minutes

## Rollback

1. **Revert any scaling change**
   - Command: `atlasctl scale svc-identity --replicas baseline`
   - Expected: Replica count returns to the baseline
2. **Re-enable any disabled flag once the cause is understood**
   - Command: `atlasctl flags enable identity-rollout`
   - Expected: Flag reports enabled

## Escalation

- Page `team-platform` via the primary rotation if not mitigated in 20 minutes.
- Escalate to the incident commander for any Sev1, or if blast radius exceeds 5.
