# Mitigating duplicate message processing on Reporting

## Symptoms

- Elevated duplicate message processing reported on `svc-reporting`.
- Alert fired from the service SLO burn-rate monitor.
- Customer-facing impact is possible if the condition persists beyond 15 minutes.

## Diagnosis

1. **Identify the last change to the service**
   - Command: `atlasctl changes list svc-reporting --since 4h`
   - Expected: A change id, or an empty list if none
2. **Check upstream dependency health**
   - Command: `atlasctl deps health svc-reporting`
   - Expected: Each dependency reports healthy or degraded
3. **Inspect the error budget burn rate**
   - Command: `atlasctl slo burn svc-reporting`
   - Expected: Burn rate as a multiple of budget

## Mitigation

1. **Disable the offending feature flag**
   - Command: `atlasctl flags disable reporting-rollout`
   - Expected: Flag reports disabled for all cohorts
2. **Purge the affected cache namespace**
   - Command: `atlasctl cache purge svc-reporting --namespace hot`
   - Expected: Cache hit ratio recovers over 5 minutes
3. **Drain and restart unhealthy replicas**
   - Command: `atlasctl replicas recycle svc-reporting --unhealthy-only`
   - Expected: Unhealthy replicas replaced one at a time
4. **Fail over to the secondary region**
   - Command: `atlasctl failover svc-reporting --to westeurope`
   - Expected: Traffic served from the secondary region
5. **Scale out the service by one step**
   - Command: `atlasctl scale svc-reporting --replicas +2`
   - Expected: Replica count increases; p95 begins to fall within 3 minutes

## Rollback

1. **Revert any scaling change**
   - Command: `atlasctl scale svc-reporting --replicas baseline`
   - Expected: Replica count returns to the baseline
2. **Re-enable any disabled flag once the cause is understood**
   - Command: `atlasctl flags enable reporting-rollout`
   - Expected: Flag reports enabled

## Escalation

- Page `team-data` via the primary rotation if not mitigated in 20 minutes.
- Escalate to the incident commander for any Sev1, or if blast radius exceeds 5.
