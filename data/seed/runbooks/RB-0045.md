# Mitigating elevated p95 latency on Recommendations

## Symptoms

- Elevated p95 latency reported on `svc-recommendations`.
- Alert fired from the service SLO burn-rate monitor.
- Customer-facing impact is possible if the condition persists beyond 15 minutes.

## Diagnosis

1. **Inspect the error budget burn rate**
   - Command: `atlasctl slo burn svc-recommendations`
   - Expected: Burn rate as a multiple of budget
2. **Review recent log volume for new signatures**
   - Command: `atlasctl logs top-errors svc-recommendations --window 30m`
   - Expected: Ranked error signatures with counts
3. **Verify connection pool utilisation**
   - Command: `atlasctl pool stats svc-recommendations`
   - Expected: In-use versus maximum connections
4. **Check for correlated incidents on dependencies**
   - Command: `atlasctl incidents related svc-recommendations`
   - Expected: Open incidents on services this one needs

## Mitigation

1. **Purge the affected cache namespace**
   - Command: `atlasctl cache purge svc-recommendations --namespace hot`
   - Expected: Cache hit ratio recovers over 5 minutes
2. **Drain and restart unhealthy replicas**
   - Command: `atlasctl replicas recycle svc-recommendations --unhealthy-only`
   - Expected: Unhealthy replicas replaced one at a time
3. **Fail over to the secondary region**
   - Command: `atlasctl failover svc-recommendations --to westeurope`
   - Expected: Traffic served from the secondary region
4. **Scale out the service by one step**
   - Command: `atlasctl scale svc-recommendations --replicas +2`
   - Expected: Replica count increases; p95 begins to fall within 3 minutes

## Rollback

1. **Revert any scaling change**
   - Command: `atlasctl scale svc-recommendations --replicas baseline`
   - Expected: Replica count returns to the baseline
2. **Re-enable any disabled flag once the cause is understood**
   - Command: `atlasctl flags enable recommendations-rollout`
   - Expected: Flag reports enabled

## Escalation

- Page `team-discovery` via the primary rotation if not mitigated in 20 minutes.
- Escalate to the incident commander for any Sev1, or if blast radius exceeds 5.
