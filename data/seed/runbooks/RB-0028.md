# Mitigating connection pool exhaustion on Email Gateway

## Symptoms

- Elevated connection pool exhaustion reported on `svc-email-gateway`.
- Alert fired from the service SLO burn-rate monitor.
- Customer-facing impact is possible if the condition persists beyond 15 minutes.

## Diagnosis

1. **Confirm the alert is not a monitoring artefact**
   - Command: `atlasctl metrics show svc-email-gateway --window 15m`
   - Expected: Error rate and p95 both elevated in the same window
2. **Identify the last change to the service**
   - Command: `atlasctl changes list svc-email-gateway --since 4h`
   - Expected: A change id, or an empty list if none
3. **Check upstream dependency health**
   - Command: `atlasctl deps health svc-email-gateway`
   - Expected: Each dependency reports healthy or degraded

## Mitigation

1. **Disable the offending feature flag**
   - Command: `atlasctl flags disable email-gateway-rollout`
   - Expected: Flag reports disabled for all cohorts
2. **Purge the affected cache namespace**
   - Command: `atlasctl cache purge svc-email-gateway --namespace hot`
   - Expected: Cache hit ratio recovers over 5 minutes
3. **Drain and restart unhealthy replicas**
   - Command: `atlasctl replicas recycle svc-email-gateway --unhealthy-only`
   - Expected: Unhealthy replicas replaced one at a time
4. **Fail over to the secondary region**
   - Command: `atlasctl failover svc-email-gateway --to westeurope`
   - Expected: Traffic served from the secondary region
5. **Scale out the service by one step**
   - Command: `atlasctl scale svc-email-gateway --replicas +2`
   - Expected: Replica count increases; p95 begins to fall within 3 minutes
6. **Roll back the most recent change**
   - Command: `atlasctl rollback svc-email-gateway --change CHG-2026-0001`
   - Expected: Previous revision serving traffic
7. **Shed non-critical traffic**
   - Command: `atlasctl traffic shed svc-email-gateway --class low --percent 25`
   - Expected: Low-priority request volume drops

## Rollback

1. **Revert any scaling change**
   - Command: `atlasctl scale svc-email-gateway --replicas baseline`
   - Expected: Replica count returns to the baseline
2. **Re-enable any disabled flag once the cause is understood**
   - Command: `atlasctl flags enable email-gateway-rollout`
   - Expected: Flag reports enabled

## Escalation

- Page `team-messaging` via the primary rotation if not mitigated in 20 minutes.
- Escalate to the incident commander for any Sev1, or if blast radius exceeds 5.
