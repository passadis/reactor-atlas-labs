# Mitigating expired downstream certificate on Ledger

## Symptoms

- Expired downstream certificate reported on `svc-ledger`.
- Alert fired from the service SLO burn-rate monitor.
- Customer-facing impact is possible if the condition persists beyond 15 minutes.

## Diagnosis

1. **Check for correlated incidents on dependencies**
   - Command: `atlasctl incidents related svc-ledger`
   - Expected: Open incidents on services this one needs
2. **Confirm the alert is not a monitoring artefact**
   - Command: `atlasctl metrics show svc-ledger --window 15m`
   - Expected: Error rate and p95 both elevated in the same window
3. **Identify the last change to the service**
   - Command: `atlasctl changes list svc-ledger --since 4h`
   - Expected: A change id, or an empty list if none

## Mitigation

1. **Scale out the service by one step**
   - Command: `atlasctl scale svc-ledger --replicas +2`
   - Expected: Replica count increases; p95 begins to fall within 3 minutes
2. **Roll back the most recent change**
   - Command: `atlasctl rollback svc-ledger --change CHG-2026-0001`
   - Expected: Previous revision serving traffic
3. **Shed non-critical traffic**
   - Command: `atlasctl traffic shed svc-ledger --class low --percent 25`
   - Expected: Low-priority request volume drops
4. **Increase the connection pool ceiling**
   - Command: `atlasctl pool resize svc-ledger --max 200`
   - Expected: Pool utilisation falls below 80 percent
5. **Disable the offending feature flag**
   - Command: `atlasctl flags disable ledger-rollout`
   - Expected: Flag reports disabled for all cohorts
6. **Purge the affected cache namespace**
   - Command: `atlasctl cache purge svc-ledger --namespace hot`
   - Expected: Cache hit ratio recovers over 5 minutes
7. **Drain and restart unhealthy replicas**
   - Command: `atlasctl replicas recycle svc-ledger --unhealthy-only`
   - Expected: Unhealthy replicas replaced one at a time

## Rollback

1. **Revert any scaling change**
   - Command: `atlasctl scale svc-ledger --replicas baseline`
   - Expected: Replica count returns to the baseline
2. **Re-enable any disabled flag once the cause is understood**
   - Command: `atlasctl flags enable ledger-rollout`
   - Expected: Flag reports enabled

## Escalation

- Page `team-finance` via the primary rotation if not mitigated in 20 minutes.
- Escalate to the incident commander for any Sev1, or if blast radius exceeds 5.
